## Free shipping and the real checkout total

Shipping can change the value of a coupon. iHerb’s US shipping page currently displays free shipping on orders over **$25**, while other iHerb pages have shown different thresholds such as $30 depending on the page, location, or promotion context.

Because the threshold can vary, use the amount shown in your cart for the selected delivery address. Do not add unnecessary products simply to reach a free-shipping threshold unless the extra items are useful and the final total is lower than paying the shipping charge.

A good basket check looks like this:

- Merchandise subtotal before discounts
- Eligible discount
- Excluded products
- Shipping charge
- Tax
- Cashback eligibility
- Final amount charged

A code can reduce the product subtotal but still leave a shipping fee. A sale item can be cheaper than a percentage code. A cashback order can look more expensive at checkout because the cashback is paid later rather than deducted immediately.

For a normal shopper, the simplest rule is: choose one saving route for the order, check the terms, and confirm the final cart total.

## Promo-code rules that can make a code fail

An iHerb promo code may be rejected for several reasons:

- The account is not eligible for the offer.
- The code is limited to a first order.
- The order is placed in the wrong country or currency.
- The product or brand is excluded.
- The minimum order value is not met.
- The code has expired.
- Another promotion is already applied.
- The code is limited to the iHerb app.
- The order includes a product category excluded from promotions.
- The code cannot be combined with a Rewards discount.

iHerb’s official rules state that only one promotional code may be entered per order. They also explain that exclusions can apply to brands, categories, order thresholds, promotional periods, and specific products.

If a code fails, do not keep changing unrelated cart items blindly. First check whether the code is intended for your country, customer status, channel, and product category. The cart usually provides a more reliable answer than a third-party coupon page.
